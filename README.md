# الأمن العام | مقاطعة ثرونز
مشروع FiveM RP مستقل. واجهة عربية مع شعار وفيديو ونجوم متحركة. لا يجمع كلمات مرور Discord.

## التشغيل
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (لا ترفع .env).
2. أنشئ تطبيقاً في https://discord.com/developers/applications ثم أضف Bot. ادعُ البوت إلى السيرفر بصلاحيات View Channel وSend Messages وEmbed Links في روم سجل خاص بالموظفين. لا يحتاج Administrator.
3. في OAuth2 أضف Redirect URL مطابقاً لـ BASE_URL/auth/callback.
4. أنشئ PostgreSQL واستضافة Node.js (مثل Render). أمر البناء npm install وأمر التشغيل npm start. أضف متغيرات .env.example إلى إعدادات الاستضافة. BASE_URL هو رابط HTTPS النهائي دون شرطة أخيرة. SESSION_SECRET قيمة عشوائية طويلة. لا تشارك التوكن أو Client Secret.
5. فعّل Developer Mode في Discord وانسخ Server ID وRole IDs وChannel ID إلى المتغيرات المطابقة. الرولات غير المضبوطة لا تمنح صلاحيات.
6. افتح الرابط وسجل الدخول. المستخدم يجب أن يكون عضواً في السيرفر. تحقق بحساب عادي وحساب شرطة وحساب قاضٍ قبل الاستخدام.

## الوظائف
شكوى، قبول/رفض، تعيين محققين بواسطة القاضي، تسجيل النتائج، إعادة التحقيق، جلسة، استدعاء، حكم، تعاميم، سجل إرسال الإشعارات. الأدلة روابط فقط. الإشعارات الخاصة قد تفشل إذا أغلق العضو الخاص؛ يظهر الفشل في السجل. سجل الروم يرسل عنوان الإجراء ورقم القضية دون تفاصيل سرية. لا يطبق الحكم على رولات Discord تلقائياً. لا يوجد تسجيل دخول محلي أو رفع ملفات أو حذف مؤقت في هذه النسخة. لم يتم اختبار الاتصال الفعلي بديسكورد أو PostgreSQL لعدم توفر بيانات الاعتماد. GitHub Pages وحده لا يشغل المشروع.
